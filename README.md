# Paradise Nursery

Paradise Nursery is a React and Redux Toolkit online houseplant shopping application. Browse plants by category, add products to a shopping cart, update quantities, remove items, and view the order total.

## Features
- Landing page with company name and Get Started button
- About Us company information
- Plant catalog with three categories and six plants per category
- Add-to-cart buttons and live cart item count
- Shopping cart with quantity controls, item removal, subtotals, and total
- Continue shopping and Coming Soon checkout actions

## Run locally
1. Install Node.js (LTS).
2. Open this project folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open the local URL printed by Vite.

Built with React, Vite, and Redux Toolkit.
